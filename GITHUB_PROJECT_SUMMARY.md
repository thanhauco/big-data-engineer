# Big Data Engineer – Azure Analytics Portfolio

## Role Focus

Big Data Engineer with hands-on experience designing and implementing cloud-native data pipelines for the Microsoft Azure ecosystem. Skilled in Spark, PySpark, Scala, SQL, ADLS, Synapse, Cosmos DB, Kusto, and Microsoft Fabric.

## Core Technical Skills

- Synapse Analytics and SQL-based warehouse patterns
- Spark and PySpark ETL for large-scale transformations
- Scala for distributed data processing and batch workloads
- ADLS and Cosmos data access strategies
- Delta and lakehouse-oriented design patterns
- Kusto operational analytics and alerting
- Microsoft Fabric / OneLake reporting workflows

## Portfolio Project

This repository demonstrates an end-to-end Azure analytics solution for retail and telemetry workloads, covering:

- source ingestion from ADLS and document storage
- bronze/silver/gold processing with Spark
- curated business aggregation and revenue analysis
- Synapse and Fabric-ready query patterns
- operational monitoring with Kusto
- portfolio-friendly architecture and project documentation

## Value to Hiring Managers

This project shows the ability to move from raw data to trusted, queryable business datasets while maintaining reliability, partitioning, and observability. It reflects the type of architecture and engineering discipline expected in enterprise Azure data teams.

## Key Outcome

Built a portfolio-ready reference project that demonstrates real-world data engineering thinking across storage, transformations, analytics, and monitoring.
